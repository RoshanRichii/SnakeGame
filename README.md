# 🐍 Snake Game (Python)

A classic **Snake Game** built entirely in **Python**. Control the snake, collect food to grow longer, and try to achieve the highest score without colliding with the walls or your own body.

## ✨ Features

* Classic Snake gameplay
* Smooth keyboard controls
* Random food generation
* Score tracking
* Game Over and restart functionality
* Simple and lightweight implementation

## 🛠️ Built With

* **Python**
* **Turtle Graphics** *(or replace this if you used another library, such as Pygame)*

## 🎮 How to Play

1. Run the Python file.
2. Use the arrow keys to control the snake.
3. Eat the food to grow and increase your score.
4. Avoid hitting the walls or the snake's own body.
5. Try to beat your highest score!
